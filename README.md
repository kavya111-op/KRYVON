# KRYVON
### AI-Powered Autonomous Commerce

**Discover smarter. Decide faster. Shop better.**

KRYVON is an AI-powered commerce platform designed to transform traditional online shopping into an intelligent, personalized and streamlined experience.

By combining AI-driven product discovery, intelligent recommendations, product comparison and integrated payment capabilities, KRYVON aims to make shopping easier and more efficient.

---

## 🚀 Vision

To make online shopping more intelligent by bringing product discovery, decision-making and purchasing into one connected experience.

## 💡 The Problem

Traditional e-commerce platforms often require customers to:
- Search through hundreds of products.
- Compare specifications and prices manually.
- Spend time identifying products that match their needs.
- Navigate multiple steps before completing a purchase.

## ✨ Our Solution

KRYVON brings these activities together through an intelligent shopping experience.

The platform aims to understand customer requirements, discover relevant products, provide recommendations and simplify the purchasing journey.

## ⚡ Key Features

- **AI Shopping Assistant:** Conversational shopping assistance.
- **Smart Product Discovery:** Find products based on customer requirements.
- **Intelligent Recommendations:** Discover relevant products.
- **Product Comparison:** Evaluate available shopping options.
- **Shopping Cart:** Manage selected products.
- **PayPal Integration:** Integrated online payment workflow.
- **Responsive Interface:** Access the platform across devices.

*Note: AI assistant capabilities are currently under development and will be updated as the implementation is completed.*

## 💻 Getting Started

### Prerequisites

- Git
- A modern web browser
- Visual Studio Code (recommended)

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/kryvon-ai-commerce.git
```

Navigate to the project:

```bash
cd kryvon-ai-commerce
```

Open the project in VS Code:

```bash
code .
```

Run the frontend using VS Code Live Server or your configured local development server.

For backend setup and API configuration, refer to `docs/SETUP_GUIDE.md`.

## 🔐 Environment Variables

Sensitive credentials must never be committed to GitHub.

Create a local `.env` file and configure the required variables according to `.env.example`.
